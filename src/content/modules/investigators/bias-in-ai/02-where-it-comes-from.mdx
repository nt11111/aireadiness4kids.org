## 1. The data it learns from

A tool learns from its <Vocab term="training data" />. If the data leaves people out, or comes from a time when some people were treated unfairly, the tool can pick up those patterns and repeat them.

## 2. The goal people choose

Someone decides what the tool should do and what counts as a good answer. "Find applicants like the people we hired before" sounds reasonable. But if past hiring was unfair, that goal asks the tool to copy the unfairness. One large tech company reportedly stopped using an experimental résumé-screening tool after finding it favored men. ## 3. How it's tested and used

Even a well-built tool can cause harm if it's only tested on some kinds of people, or used for a job it wasn't built for.

Some police departments have used tools that predict where crime might happen, based on past arrest records. Critics argue this can send more officers to the same neighborhoods, which leads to more arrests there, which the tool then treats as proof it was right. [CITATION NEEDED] That kind of cycle is called a <Vocab term="feedback loop" />.
