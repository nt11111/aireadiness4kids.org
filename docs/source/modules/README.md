## Format

`ARK_CURRICULUM_GUIDE.md` (v1.4) in this folder defines the module structure and the tags (`[CALLOUT kind]`, `[VOCAB term]`, `[FIGURE]`, `[SORT]`, `[SCENARIO]`, `[CHECK]`, `[REFLECT]`, `[DISCUSS]`, `[RECAP]`, `[TRY]`), the Play it step, Level up boxes, and the ARK's view block. Sections 5 to 7b are the format reference. The rest of that file is for writing sessions with Claude and doesn't apply to building the site.

AI Literate files use a plainer layout (labels such as `OBJECTIVES`, `STEP 1: Hook (explainer, 5 min)`, `Title:`), but the same tags.
