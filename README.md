# ARK · AI Readiness for Kids — website

Live at **https://aireadiness4kids.org**. Built with React, Vite, Tailwind, and deployed automatically to GitHub Pages on every push to `main`.

## Edit content
All copy lives in `src/app/lib/content.ts`. Pages are in `src/app/pages/`. Brand assets are in `public/brand/`.

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Push to `main`. GitHub Actions builds the site and publishes it (about 1 to 2 minutes).
